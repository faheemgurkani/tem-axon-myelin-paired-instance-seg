# Does any axon/myelin work already close the "paired axon–myelin instance" gap? (status 12 Nov 2026)

Scope: primary-source check of (1) what ASTIH's instance metric actually measures and (2) whether any tool predicts axon + myelin jointly as a nested instance or trains on g-ratio. Builds on `docs/reports/TEM axon myelin segmentation review.md` (10–11 Nov 2026). Items already verified there are re-cited, not re-fetched, except where new evidence changes the picture. Code was read directly from GitHub with `gh api` on 12 Nov 2026.

## Key question 1: Is there ANY paper or repo that predicts myelinated fibers as instances with axon and myelin jointly (end-to-end), or trains on g-ratio error?

### Takeaway
No. Every tool found still links axon to myelin with a hand-written post-hoc rule, and none trains on g-ratio or any other morphometric loss. The closest counter-example is **new and must be cited**: **AxonPath** (Carrillo-Barberà, Bankhead, Williams et al.; code and models released Sep–Oct 2026; preprint "in preparation", not peer-reviewed). It is one U-Net with three heads: semantic, fibre distance and axon distance. So the network does predict fibre and axon instance cues jointly. Its decoder then builds the Fibre > InnerCylinder > Axon hierarchy with two seeded watersheds and an overlap rule (inner cylinder accepted if ≥ 90% lies inside one fibre). Its loss is Dice-CE + MSE, with no g-ratio term. Our claim must therefore be narrowed: "no method makes valid pairing hold by construction or optimises g-ratio". Saying "no model predicts fibre and axon together" is now false.

### Cited Findings

**Closest counter-example: AxonPath (new, Sep–Oct 2026, not peer-reviewed)**
- README: "AxonPath uses a U-Net with three output heads: a **semantic head** that classifies each pixel as background, myelin or inner cylinder (the axon plus the inner tongue of the myelin sheath); a **fibre distance head** and an **axon distance head** that predict skeleton-aware distance transforms (SDTs), which are split into individual fibres and axons by seeded watershed. The result is a hierarchy of objects, Fibre > InnerCylinder > Axon, from which g-ratios … are computed." — [paucabar/axonpath README](https://github.com/paucabar/axonpath)
- How the parts are linked (rule-based): `map_axon_labels_to_fibres` docstring: "Assign each label_img2 fragment to the label_img1 object it overlaps most with, provided that overlap covers at least `min_overlap_frac` of the fragment (IoC metric)… threshold = 0.9 (90% of inner cylinder must fall within the matched fibre)… Unmatched fragments are set to 0." Inner cylinders come from the semantic map via connected components, "each region given the ID of the fibre that contains it". `merge_unmatched_fibres` reassigns fibres without an axon to the nearest matched fibre (edge distance ≤ 1 px). — [label_ops.py](https://github.com/paucabar/axonpath/blob/main/axonpath/utils/label_ops.py); [post_processing.py](https://github.com/paucabar/axonpath/blob/main/axonpath/inference/post_processing.py)
- Loss: `compute_loss` = weighted Dice + CE (semantic) + MSE (fibre SDT) + MSE (axon SDT). There is no morphometric term. — [losses.py](https://github.com/paucabar/axonpath/blob/main/axonpath/utils/losses.py)
- Evaluation: "reports F1, precision and recall for fibres, inner cylinders and axons, with objects matched at IoU thresholds from 0.5 to 0.9". This is per-object-class detection, not pair correctness. No published numbers were found. — [README](https://github.com/paucabar/axonpath)
- Models: Zenodo 22982902 (26 Sep 2026; `em_cns` at 0.008 µm/px, `em_pns` at 0.03 µm, `brightfield` at 0.071 µm; CC-BY-4.0). Authors: Carrillo-Barberà, Goldsborough, O'Callaghan, Poveda Sabuco, Sgattoni, Gomez-Sanchez, Rondelli, Williams, Bankhead. — [Zenodo 22982902](https://zenodo.org/records/22982902)
- QuPath extension (repo created 26 Sep 2026): "A preprint describing AxonPath is in preparation." — [qupath-extension-axonpath](https://github.com/paucabar/qupath-extension-axonpath)
- Note: the EM CNS model runs at 8 nm/px, about 3.7× coarser than the challenge's 2.152 nm/px.

### Inferences
- All tools share one pattern: the network (if any) outputs per-compartment maps or distance/flow cues, and a hand-written rule (centroid seed watershed, nearest centroid, IoC overlap, contour nesting, spreadsheet column prefix) makes the pairs. **Learned joint cues exist (AxonPath, optic-nerve dual decoder); a learned or by-construction pairing does not.**
- AxonPath's three-head design is close to what the earlier review recommends (fibre separation + within-fibre parts). It differs in that the fibre and axon watersheds are independent, so mismatches are possible: an axon fragment spanning two fibres, an inner cylinder with < 90% inside its fibre gets dropped, and a fibre with two axons is possible. That leaves room for a "valid by construction" claim. It also means a reviewer will expect AxonPath as a baseline. It is open, CC-BY and includes a CNS-TEM model.
- The "no g-ratio loss" claim survives, but only as "not found within search limits". Morphometric losses in other fields could exist under other names.
- **Rephrasing needed:** "no published model predicts axon and its ring jointly" → "every published pipeline, including the multi-head AxonPath and the dual-decoder optic-nerve nnU-Net, recovers the axon–myelin pairing with post-hoc rules; none makes a valid pair a property of the representation, and none optimises per-fiber g-ratio."

### Gaps
- AxonPath's preprint is unpublished, so no accuracy, g-ratio or pairing numbers exist. Its inference code that combines the axon SDT watershed with fibres (pipeline.py) was only partly read.
- The optic-nerve paper never states how inner and outer masks are paired (supplementary Tables S2–S5 not read). The code repo was 404 in the prior review.
- Naito et al. ("Identification and segmentation of myelinated nerve fibers in a cross-sectional optical microscopic image using a deep learning model", ~2017) appears to do detection-then-per-fibre segmentation, a two-stage instance approach. It was not read; status unverified. — [ResearchGate](https://www.researchgate.net/publication/319288238_Identification_and_segmentation_of_myelinated_nerve_fibers_in_a_cross-sectional_optical_microscopic_image_using_a_deep_learning_model)

## Key question 2: Is "79% fiber F1" a fair statement of "pairing unsolved", or must it be rephrased?

### Takeaway
It must be rephrased. ASTIH's instance metric is **fiber detection**: StarDist matching of fiber (axon ∪ myelin) instances at IoU 0.3/0.5. It never checks whether the right axon is paired with the right ring. ASTIH says nothing about pairing correctness, attributes the gap to the watershed's separation and boundary sensitivity, and the same pipeline scores **F1 0.949 on TEM2**. So 0.791 is "fiber-instance error from semantic→instance conversion on TEM1". It is not a measured pairing-error rate. Pairing errors would show up inside that number (a wrongly split shared sheath lowers fiber IoU; a fragmented axon creates an extra fiber), but ASTIH cannot separate them from detection and delineation errors.

### Cited Findings
- What is predicted for evaluation: "we apply the postprocessing pipeline described in Sec. 2.2.2 to both prediction and ground-truth masks… Due to the strict boundary delineation enforced during annotation, this yields a perfect instance segmentation for the ground truth." Each label "corresponds to an individual myelinated fiber". — [ASTIH §2.2.2–2.2.3](https://raw.githubusercontent.com/mlresearch/v315/main/assets/collin26a/collin26a.pdf)
- Purpose of the metric: "to quantify the ability to localize individual axons, we additionally compute object-level detection metrics, including precision, recall, and F1-score"; matching with `stardist.matching`; "To decouple detection performance from segmentation precision, we evaluated detection metrics at two IoU thresholds: a permissive one at 0.3, and a more standard value at 0.5." — [ASTIH §2.2.3](https://raw.githubusercontent.com/mlresearch/v315/main/assets/collin26a/collin26a.pdf)
- Cellpose "on the combined axon and myelin masks to segment individual fibers… this single-class approach does not support myelin morphometry". So the 0.882 comparator has no axon/myelin split at all, and its "pairing" cannot be wrong by definition. — [ASTIH §2.2.1](https://raw.githubusercontent.com/mlresearch/v315/main/assets/collin26a/collin26a.pdf)
- Table 4, TEM1 nnU-Net: IoU 0.3 → P 0.837 / R 0.955 / F1 0.887; IoU 0.5 → P 0.747 / R 0.851 / F1 0.791. TEM2 nnU-Net: 0.965 (0.3) and **0.949 (0.5)**. Cellpose TEM1: 0.882 at both thresholds (P 0.990, R 0.797). — [ASTIH Table 4](https://raw.githubusercontent.com/mlresearch/v315/main/assets/collin26a/collin26a.pdf)
- Authors' explanation: "nnU-Net achieves higher recall on the high-resolution TEM datasets, indicating it effectively identifies nearly all fibers, though its watershed-based separation is less robust than Cellpose's flow-based masks." And: "The watershed post-processing applied to nnU-Net masks is sensitive to minor boundary erosions or dilations, leading to a gradual, linear reduction in overlap as the strictness increases" (App. B, on a BF1 image). — [ASTIH §3, App. B](https://raw.githubusercontent.com/mlresearch/v315/main/assets/collin26a/collin26a.pdf)
- Only limitation statement: "while the inference postprocessing step outputs instance segmentations, the current watershed-based method may struggle in densely packed or pathological tissues." No g-ratio error, no pairing-violation count, no merge/split breakdown. — [ASTIH §4](https://raw.githubusercontent.com/mlresearch/v315/main/assets/collin26a/collin26a.pdf)
- Fig. 5 caption (nnU-Net failures): "Red boxes highlight spurious predictions". These are false-positive objects, not mispairings. — [ASTIH Fig. 5](https://raw.githubusercontent.com/mlresearch/v315/main/assets/collin26a/collin26a.pdf)
- GT topology is enforced: "an automated validation script verified topological constraints… (e.g., ensuring every myelin region contained exactly one axon region)". GT pairing is therefore trivially valid, while predictions are never checked against this constraint in the metrics. — [ASTIH §2.1.2](https://raw.githubusercontent.com/mlresearch/v315/main/assets/collin26a/collin26a.pdf)

### Inferences
- Decomposing TEM1 nnU-Net (our reading of Table 4): at IoU 0.3 recall is 0.955, so few GT fibers are missed outright; precision 0.837 means ~16% of predicted fibers are spurious or fragments. Going to IoU 0.5 removes another ~0.10 of recall and precision, i.e. matched fibers with 0.3 < IoU ≤ 0.5. Both effects fit the ADS watershed failure modes (fragmented axon → two fibers; shared-sheath myelin split along a flat basin → poor fiber IoU), and these are pairing-adjacent. They equally fit plain semantic false positives. ASTIH gives no breakdown, so "79% shows pairing is unsolved" overclaims.
- TEM2's 0.949 with the identical pipeline shows the watershed is not uniformly bad. The TEM1 gap is dataset-dependent (TEM2 is 4.93 nm/px and high-pressure frozen; TEM1 has cuprizone pathology at 2.36 nm/px).
- Suggested wording: "On ASTIH TEM1, near-ceiling compartment Dice (0.974/0.924) turns into only 0.791 fiber F1@IoU0.5 once the standard axon-seeded watershed converts semantic masks to fibers (0.882 for a fiber-only Cellpose that cannot separate axon from myelin). No published benchmark measures whether each axon is paired with its own sheath, and none reports per-fiber g-ratio error." Then motivate the oracle-pairing experiment as the way to measure pairing error directly.
- Caveat for any "Cellpose beats nnU-Net" framing: Cellpose's TEM1 recall is 0.797, and its output gives no g-ratio. Neither baseline solves the paired task.

### Gaps
- ASTIH reports no merge/split counts or per-error-type breakdown. Measuring the pairing share of the 0.791 needs our own rerun (released TEM1 model + GT) with merge/split and pairing-violation counters.
- Whether TEM1 errors cluster in cuprizone (demyelinated, thin-sheath) images is not reported.

## Key question 3: Any 2026 work (Aug–Nov) that is new since the earlier review?

### Takeaway
Three items are new or newly characterised. None closes the gap. **AxonPath models + training code + QuPath extension** (Sep–Oct 2026; the dataset was already known) is the important one: a three-head network with rule-based hierarchy assembly that should become a baseline. **AxonID** (VCU, GitHub, Oct 2026) is a semantic UNet++ plus watershed and centroid matching for toluidine-blue PNS. **ADS** added only a morphometrics-filtering/axon-counting feature (Sep 2026) and a bug fix (30 Oct). Two items from the user's list predate August: Won et al. (Sci Rep, July 2026) and MyeliMetric (Dec 2025). Neither adds an instance model.

### Inferences
- The field is converging on "multi-head network + rule-based hierarchy" (AxonPath) and "semantic + watershed + centroid match" (ADS, AxonID, Won). A paper claiming novelty must contrast with AxonPath explicitly, ideally running it as a baseline. Its em_cns model is at 8 nm/px, so rescale challenge images about 0.27× or fine-tune with its released training code.
- AxonPath's evaluator scores fibres, inner cylinders and axons separately at IoU 0.5–0.9. It still has no pair-correctness or per-fiber g-ratio metric, so the evaluation gap also stands.

### Gaps
- AxonPath preprint not yet out (citation "in preparation"). It could appear any day with numbers on AxonPath CC TEM, so it should be re-checked before submission.
- ResearchGate's copy of Won et al. describes "twenty-four rats… 20 mm isografts", which conflicts with the six-nerve crush design on nature.com. The nature.com text was used here.
- No Chrome session was used. Paywalled or JS-only sources (Google Scholar, MICCAI 2026 LNCS, theses) were not checked.
